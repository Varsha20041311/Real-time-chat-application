WHAT IT DOES:
=============

This is a real-time chat application that allows multiple users to communicate
instantly through a web interface. Messages are transmitted using WebSocket
technology (Socket.IO), providing instant delivery without page refreshes.

Key Features:
  ✓ Real-time messaging between multiple users
  ✓ Instant message broadcasting
  ✓ Simple, clean user interface
  ✓ WebSocket-based communication
  ✓ Multi-user support

HOW IT WORKS:
=============

Step 1: User opens the application in their browser
   → React app loads
   → Socket.IO client connects to server
   → Connection established with unique ID

Step 2: User types a message and clicks "Send"
   → Message captured from input field
   → Sent to server via WebSocket (emit 'send_message')
   → Input field cleared

Step 3: Server receives the message
   → Message received from client
   → Broadcast to ALL connected clients (emit 'receive_message')

Step 4: All clients receive the message
   → Message appears instantly in all browser windows
   → No page refresh needed
   → Real-time synchronization

HOW TO RUN:
===========

1. Start the Backend Server:
   ---------------------------
   Command:  node index.js
   Port:     5000
   URL:      http://localhost:5000

2. Start the Frontend:
   -------------------
   Commands: npm install
             npm start
   Port:     3000
   URL:      http://localhost:3000 (opens automatically)

3. Test Multi-User Chat:
   ---------------------
   Open multiple browser tabs to http://localhost:3000
   Type messages in any tab
   See messages appear instantly in all tabs
